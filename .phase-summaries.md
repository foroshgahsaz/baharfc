# Phase summaries (c4da)

> **Note:** `cursor/phase-2-search-media-c4da` is identical to phase 1 at implementation time (no search/media commit yet). Phases 3–7 stack: each branch is based on the previous phase branch.

## Phase 3 — `cursor/phase-3-profile-addresses-c4da`

**PR title:** Phase 3: Customer profile and Iran addresses

**PR body:** Adds authenticated `/account` with Livewire profile editing; Iran province/city picker (`config/iran_locations.php`); `Address` model, policy, form requests, and `SetDefaultAddress` action. Header links to account. Feature tests for auth, profile, and addresses.

**Stack base:** `cursor/phase-2-search-media-c4da` (same commit as phase 1)

---

## Phase 4 — `cursor/phase-4-cart-coupons-c4da`

**PR title:** Phase 4: Cart, coupons, and shipping

**PR body:** `CartService` (session for guests, DB for authenticated users, merge on login). Tables: `cart_items`, `coupons`, `shipping_methods`. Livewire cart page with coupon/shipping selection; PDP `AddToCart`. `CartCatalogSeeder` (BAHAR10, shipping methods). Cart feature tests.

**Stack base:** `cursor/phase-3-profile-addresses-c4da`

---

## Phase 5 — `cursor/phase-5-orders-checkout-c4da`

**PR title:** Phase 5: Orders and checkout

**PR body:** `orders` / `order_items` with price snapshots. `OrderStatus` enum. `CreateOrderFromCart` action. Auth-only checkout Livewire flow; payment stub page. Filament `OrderResource` for admin status management. Checkout tests.

**Stack base:** `cursor/phase-4-cart-coupons-c4da`

---

## Phase 6 — `cursor/phase-6-gateways-mellat-parsian-c4da`

**PR title:** Phase 6: Mellat and Parsian payment gateways

**PR body:** `PaymentGatewayInterface`, sandbox-aware `MellatGateway` and `ParsianGateway`, `payments` table, `PaymentService`. Checkout payment selection; signed callback URLs; rate-limited `/payment/callback/{gateway}` with amount verification. `config/payment.php` + `.env.example`. Filament `PaymentResource`. Payment tests.

**Stack base:** `cursor/phase-5-orders-checkout-c4da`

---

## Phase 7 — `cursor/phase-7-digipay-snapp-c4da`

**PR title:** Phase 7: DigiPay and SnappPay checkout UI

**PR body:** `DigiPayGateway` and `SnappPayGateway` registered in `PaymentService`. Checkout UI badges and helper copy for wallet/installment options; sandbox flow covered by tests.

**Stack base:** `cursor/phase-6-gateways-mellat-parsian-c4da`
